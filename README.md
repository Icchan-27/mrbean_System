# Mr. Bean Coffee POS & Management System

A web-based application developed to manage a coffee shop's daily operations, including sales transactions, menu management, inventory tracking, and sales monitoring.

## Features
- Point-of-Sale (POS) and order processing
- Cash payment and change calculation
- Menu management
- Inventory and ingredient tracking
- Automatic ingredient deduction based on menu recipes
- Low-stock monitoring
- Sales reports and transaction history
- Role-based access for owners and cashiers

## Technologies Used
- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript

## Project Description
This system was developed to streamline coffee shop operations by integrating sales processing and inventory management into a single application. It helps manage transactions, monitor ingredient stocks, track sales, and simplify daily business operations.
